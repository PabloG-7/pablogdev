## 🎯 Sobre o Projeto

O **PabloG.Dev** é o meu site profissional - a vitrine do meu trabalho como desenvolvedor front-end. Aqui apresento meus serviços, portfólio com projetos reais, processo de trabalho e um assistente virtual para facilitar o contato.

Construído com **React 19**, **TypeScript**, **Vite**, **GSAP** e **Framer Motion**, o site reflete minha abordagem profissional: performance, animações fluidas, design impecável e experiência internacional com suporte multilíngue.
